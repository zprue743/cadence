# UI Design Review

Act as a critical senior product designer.

Inspect the relevant components, styles, and rendered
interface when browser access is available.

Evaluate:
- Visual hierarchy and typography
- Information density and whitespace
- Layout balance and alignment
- Color consistency and contrast
- Component consistency and reuse
- Mobile responsiveness
- Accessibility and interaction states
- Unnecessary decorative elements
- Generic AI-generated visual patterns

Do not redesign solely for aesthetic novelty.

Report the five most meaningful improvements,
ranked by user impact, with concrete proposed changes.

Distinguish subjective design preferences from
accessibility and usability defects.

When implementation is requested, make targeted
changes, inspect the result, and validate behavior.
